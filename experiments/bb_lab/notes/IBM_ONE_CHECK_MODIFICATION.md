## 1. Results and hypotheses

Work over `R=F2[x^+/-1,y^+/-1]`. Set

```
chi=x^2+x+1,       U=y+x,       V=y+x+1,
P=x^3+y+y^2=UV+x chi,
Q_new=chi V=x^2 y+xy+y+x^3+1,
Q_old=1+(x+x^2)y^3.
```

For positive periods ell,m divisible by six, reduce coefficients
modulo `x^ell+1,y^m+1` and form the binary CSS code

```
H_X=[P | Q_new],       H_Z=[Q_new^T | P^T].
```

Here a polynomial denotes its translation matrix. The code has
`n=2 ell m`, each check has exactly eight physical sites, and its
two sector distances are equal. The following statements are proved:

1. The plane algebra is exactly the original pair's chi-primary
   quotient, including its nonreduced tangent direction. It splits
   into an F4 component of length one and an F4 component of length
   two. Its F2 dimension is six; there is no extra orbit.
2. Both `x^6+1` and `y^6+1` annihilate it. Consequently **k=12 for
   every such rectangle**, including the old exceptional periods.
3. There is an explicit nontrivial, one-row, g-only logical of weight
   `2 ell/3`. This is an actual physical weight, not the weight of an
   algebraic normal form.
4. A geometric lift argument gives the all-class, both-sector bounds

```
min(ceil(ell/3),ceil(m/2)) <= d <= 2 ell/3.             (1.1)
```

For the requested IBM frames `ell=6(r+b),m=6r`, `b in {0,1}` and
`r>=2`, this yields the rigorous growing-distance family

```
n=72r(r+b),       k=12,       2(r+b)<=d<=4(r+b).       (1.2)
```

The interval is **not an exact distance theorem**. In particular,
for square frames `ell=m=6r`, the candidate suggested by the explicit
stripe is `d=4r`; only `2r<=d<=4r` is proved here.

The new stripe rules out retaining the original proposed value
`D=6(2r+b-1)` for every `r>=2`: `4(r+b)<D` for both b values.
This is an obstruction for this modification, not for the original
IBM code. An exact theorem at a smaller growing distance remains
possible and is the unresolved target.

## 2. The plane algebra and its two actual primary ideals

Write `I=(P,Q_new)` and `M=R/I`. Two exact identities are

```
chi P+U Q_new=x chi^2,
V P+x Q_new=UV^2.                                    (2.1)
```

Thus `chi^2=0` and `UV^2=0` in M. Since `U+V=1`, the ideals
generated by U and by V^2 are comaximal. Their product vanishes,
so the Chinese remainder theorem gives

```
M = R/(I,U) direct-product R/(I,V^2).                 (2.2)
```

This is an algebra decomposition only, not a physical coordinate
decomposition.

On the first component, `U=0,V=1`, and P forces `chi=0` because x
is a unit. Hence its ideal is

```
J_simple=(chi,U),       R/J_simple=F4,       y=x.
```

On the second component, `U=1+V` and `V^2=0`. P forces `V=x chi`;
then Q_new forces `chi^2=0`. Conversely these two relations imply
P, Q_new, and V^2 vanish. Its ideal is therefore

```
J_double=(chi^2,V+x chi)
        =(chi^2,y+x^3+x^2+1),
R/J_double = F2[x^+/-1]/chi^2,
y=x+1+x chi.                                         (2.3)
```

The displayed value of y is a unit: modulo chi it is `x+1`, which
is nonzero in F4, and the remaining ideal is nilpotent. Equations
(2.2)-(2.3) prove

```
I=J_simple intersect J_double,       dim_F2 M=2+4=6.  (2.4)
```

For a precise meaning of “length two over F4,” in the second
component put `epsilon=chi` and `theta=x+chi`. Then

```
epsilon^2=0,       theta^2+theta+1=0,
x=theta+epsilon,       y=theta^2(1+epsilon).
```

Thus it is F4[epsilon]/epsilon^2. In particular the doubled component
is **not** obtained by imposing V=0 as an exact relation: its actual
tangent relation is `V=x chi`.

### 2.1 Regularity and periods

Let `L=F2[x^+/-1]`. Modulo P, the elements 1,y form a free L-basis;
y is already invertible because `y(y+1)=x^3`. Multiplication by Q_new
has matrix

```
chi [ x+1   x^3 ]
    [  1     x  ].
```

Its entry gcd is chi and its determinant is `x chi^3`. Thus its
Smith invariants are chi and chi^2, up to units. In particular
Q_new is a non-zero-divisor modulo P. Since R is a domain, P,Q_new
is a regular sequence, and its Koszul complex resolves M.

The periods annihilate M by finite identities. Indeed

```
x^6+1=(x+1)^2 chi^2,
(y^2+y+1)^2=P^2+(x^6+1),
y^6+1=(y+1)^2 (y^2+y+1)^2.                           (2.5)
```

Consequently every multiple-of-six x or y period acts as zero.

### 2.2 Exact comparison with the original ordinary component

The parent's supplied identity checks exactly. With
`B=x+x^3` and `R_0=(x+x^2)(y+1)`, it is

```
Q_old=R_0 P+B Q_new+chi^3,       x B=1+chi^2.         (2.6)
```

An equivalent directly unit-coefficient identity is

```
Q_old=R_0 P+x^2 Q_new+chi^2(1+xy).                   (2.7)
```

Together with (2.1), and invertibility of x, either proves

```
(P,Q_new)=(P,Q_old,chi^2).                            (2.8)
```

For (2.7), the reverse containment simply solves for x^2 Q_new;
the forward containment uses chi^2 in I. This is an equality of
ideals in the original Laurent coordinates.

To check that this is the *whole* ordinary primary part, rather than
a further truncation, the original multiplication matrix modulo P
has coefficients

```
a0=chi(1+x+x^3),       b0=chi(x+x^3),
T_old=[a0, b0 x^3; b0, a0+b0],
det(T_old)=chi^3 H,       H=x^7+x^6+x^4+x^2+1.
```

The two displayed quotients of a0,b0 sum to one, and `H mod chi=x^2`.
Thus the original Smith invariants are chi and chi^2 H, with H
coprime to chi. Adding chi^2 kills precisely the H-torsion summand
and changes neither ordinary primary component. This proves the
asserted exact tangent match without needing an orbit search or an
irreducibility assertion about H.

## 3. All-size homology and explicit nontriviality certificates

Put `F=x^ell+1`, `G=y^m+1`. They form a regular sequence in R, so
balanced Tor, computed with the period Koszul resolution, gives

```
H_1(K(P,Q_new) tensor R/(F,G))
  = H_1(M tensor K(F,G)) = M direct-sum M.             (3.1)
```

The last equality follows because both period operators vanish on
M, not from a semisimple character count. It proves k=12 for all
the stated periods, with no order-127 exception in this new code.

A useful concrete form of (3.1) is the following certificate. Lift
a torus cycle z to a finite Laurent vector z_tilde and write

```
D z_tilde=A F+B G,       D(f,g)=Pf+Q_new g.
```

Its period coordinates are the residues of (A,B) in M^2. For
nontriviality alone, this can also be proved without choosing a Tor
isomorphism. If z were a torus boundary, a lifted boundary equation
would read `z_tilde=delta(h)+F a+G b`, for Laurent vectors a,b. Then

```
F(A-Da)+G(B-Db)=0.
```

Exactness of the period Koszul complex implies that these two
coefficients are multiples of G,F, respectively. Reducing in M,
where P,Q_new,F,G vanish, forces both A and B to be zero. Therefore
any nonzero residue of A or B certifies an actual nontrivial class.

## 4. A physical stripe and the metric obstruction

For ell divisible by three, define the finite polynomial

```
W_ell=(1+x) sum_(j=0)^(ell/3-1) x^(3j).
```

Its exponents are distinct in the physical x period, so its weight
is exactly `2 ell/3`. The finite identity

```
chi W_ell=x^ell+1
```

gives the torus cycle

```
z_ell=(0,W_ell),
D z_ell=V(x^ell+1),       |z_ell|=2 ell/3.            (4.1)
```

Its period coordinate is `(V,0)`. This is nonzero: in J_simple,
V=1. Section 3 therefore certifies that (4.1) is not a boundary.
All assertions hold for every pair of periods in §1; the vector is
supported in one actual y row and one physical qubit block.

There is even an exact *restricted* distance statement. Among
nonzero vectors `(0,g)` with `chi g=0` on the torus, the minimum
physical weight is `2 ell/3`. On each fixed y row, the equation is
the binary recurrence

```
g_j+g_(j-1)+g_(j-2)=0.
```

Its nonzero solutions repeat one of the three triples 110,101,011;
each such row has exactly `2 ell/3` sites. All these vectors are
cycles because Q_new=chi V. Since (4.1) is nontrivial, the same
minimum is attained among the nontrivial classes represented in
this restricted subspace. This does **not** control other cycles.

This is a definite metric limitation of the modification. Keeping
the same ordinary primary ideal has introduced an actual factor
chi in one physical check and hence these cheap one-block logicals.
No ring decomposition, row operation, or local Clifford map is
being treated as a weight isometry. At the gross frame (12,6), the
new vector has weight eight. If one additionally uses the banked
original gross distance twelve, this also rules out a physical
weight-preserving logical equivalence at that frame; that comparison
alone is conditional on the banked original base distance.

## 5. A rigorous linear lower bound without a metric normal form

**Lemma 5.1 (small components lift).** Let ell,m be as in §1. Every
torus cycle of weight strictly less than

```
B=min(ceil(ell/3),ceil(m/2))
```

is a boundary.

Proof. Form the finite incidence graph of its occupied qubits and
all adjacent D-syndrome sites. Each syndrome vertex has even degree,
because the vector is a cycle. Distinct monomials in either check
remain distinct on these periods. Connected components of this
graph are themselves cycles, and their weights add.

Each incidence edge has its actual lattice displacement from the
specified monomial of P or Q_new. Traversing through one qubit,
from one adjacent syndrome site to another, changes the x coordinate
by at most three and the y coordinate by at most two. These are
the actual support spans of P and Q_new; no x quotient other than
the given torus has been introduced.

In a component with w occupied qubits, a simple graph cycle visits
at most w qubits. Its displacement in the lattice cover is a period
vector `(a ell,b m)`, and its coordinate magnitudes are bounded by
`3w,2w`. If w<B, both are strictly smaller than ell,m, respectively.
Hence every simple cycle has zero displacement. Every closed walk
is a sum of simple cycles and backtracks, so it too has zero
displacement.

Choose one vertex lift to Z^2 and lift the other vertices along
paths. The zero-displacement property makes the lifts independent
of path. They give a finite plane chain with the same incidence
relations and zero syndrome. Regularity from §2.1 makes the plane
Koszul complex exact in degree one, so this finite plane cycle is
`(Q_new h,P h)` for a finite Laurent polynomial h. Projecting h to
the torus proves that the component was a boundary. Summing over
components proves the lemma. QED.

This argument assumes neither that a global minimizer is connected
nor that an arbitrary small-looking rectangular frame injects. It
proves the required lift directly from the incidence displacements.

Let R_0 reverse both lattice coordinates. It is a permutation with
`R_0 P R_0=P^T` and `R_0 Q_new R_0=Q_new^T`. The physical permutation

```
(f,g) -> (R_0 g,R_0 f)
```

maps the two CSS cycle and boundary spaces to one another. Thus
their distances agree. Lemma 5.1 and the stripe prove (1.1) for
the full code, not just one sector or one logical class.

All cycle weights are even, since augmentation of D gives
`|f|+|g|=0 mod 2`; this can round the lower bound upward to the
next even integer. It does not close the factor-two gap in (1.2).

The family is LDPC and connected. P's support difference between
y and y^2 connects neighboring syndrome rows through f qubits;
Q_new's difference between y and xy connects neighboring syndrome
columns through g qubits. These generate the torus, and every
qubit is incident to a syndrome vertex. No extra disconnected
copies are being used to obtain the growth in (1.2).
