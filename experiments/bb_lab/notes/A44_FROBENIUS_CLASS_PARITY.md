# Frobenius preserves the mixed sector of the banked square witnesses

2026-09-08. Parent continuation of A44-S1/S2 and
`A40_PARITY_TOR_PROOF.md`. This is an all-height classification
of a specified witness family, not a distance proof or a shortening
construction. No additional witness search is used.

## 1. The class map for a simultaneous period doubling

Use the original reciprocal pair

```
alpha=bar A,       beta=bar B,
partial_1=(beta,alpha),       partial_2=(alpha,beta)^T.
```

On a torus with periods ell,m, doubling both periods gives the
well-defined F2-linear cycle map

```
D(f,g)=(beta f(x^2,y^2), alpha g(x^2,y^2)).             (1.1)
```

It maps boundaries to boundaries since

```
D(h alpha,h beta)=alpha beta h(x^2,y^2)(alpha,beta).
```

Suppose both periods are multiples of six and their order-127
sector is absent. In the natural period-Tor coordinates of the
parity theorem, the induced map is

```
(z1,z2) in M0^2  ->  (z1^2,z2^2) in M0^2.            (1.2)
```

Here M0 is the six-dimensional ordinary plane algebra for the
reciprocal pair. Inversion identifies its algebraic structure with
the M0 in the parity note. Equation (1.2) is not a statement about
coordinatewise squaring of a chosen physical homology basis.

**Proof.** Frobenius on the Laurent polynomial ring is flat: the
ring is free over its subring of squares, with basis `1,x,y,xy`.
Base change therefore takes the free resolution `K(beta,alpha)`
to `K(beta^2,alpha^2)`. It also takes the period resolution
`K(x^ell+1,y^m+1)` to that for the doubled periods. On the balanced
Tor double complex, Frobenius sends each coefficient z to z^2.

The quotient of plane modules
`R/(beta^2,alpha^2) -> R/(beta,alpha)` lifts to the chain map

```
degree 0: 1,      degree 1: diag(beta,alpha),
degree 2: alpha beta.
```

For example `(beta,alpha) diag(beta,alpha)=(beta^2,alpha^2)`,
and the degree-two identity follows by multiplying `(alpha,beta)`
by alpha beta. Composing with the Frobenius map on physical chains
gives exactly (1.1). Alternatively computing Tor with the period
resolution makes this quotient the coefficient quotient in every
degree. Both periods vanish on the surviving ordinary plane algebra,
so the resulting H1 map is precisely (1.2). The order-127 sector
cannot switch on under an index-four power-of-two cover. QED.

In particular D takes each of the three cylinder-image spaces into
itself (possibly killing part of it). It cannot take a rank-one
class to a mixed class. D is **not** asserted to be injective on
all torus homology.

## 2. After one doubling there is no further loss of class information

The image `Sq(M0)={z^2:z in M0}` of Frobenius is a reduced algebra,
and Frobenius is an automorphism of this image. This square-image
algebra is distinct from the direct sum `M0 direct-sum M0` used
for H1.

For an elementary proof first use the original, nonreciprocal plane
variables. The Smith calculation gives

```
(x^2+x+1)^2=0,       (y^2+y+1)^2=0 in M0.
```

Consequently the square-image algebra is generated by x^2 and y^2,
each satisfying `Z^2+Z+1=0`. It is a quotient of

```
F4 tensor_F2 F4 = F4 direct-product F4.
```

A quotient of this product of fields is again a product of fields,
so it is reduced; Frobenius is bijective on it. Inversion of x,y
does not change this conclusion for the reciprocal pair. No claim
that arbitrary quantum-class minima are preserved is involved.

It follows that after one application of D, further doublings
preserve whether each period component is zero and whether the two
components are equal. Thus rank-one versus mixed classification is
stable from that point onward. A difference killed by the *first*
Frobenius remains possible, so omitting the first-step qualification
would be incorrect.

## 3. Applying this to W_r

For `r=2^a`, let the banked original-square witness be

```
S_r=1+(xy)^(2r)+(xy)^(4r),
W_r=(S_r x^r beta^(r-1), S_r y^r alpha^(r-1))
```

on `(6r,6r)`. Squaring S_r gives S_(2r), so direct substitution
in (1.1) proves `D(W_r)=W_(2r)`.

There is also a direct, entirely symbolic certificate of its two
period components. Define the finite Laurent polynomials

```
C=x^-3 y^2+x^-1 y^4+y^7,       D0=x+y.
```

Multiplication of the six-term W1 gives the exact plane identity

```
beta (S_1 x)+alpha (S_1 y)
  = (x^6+1) C+(y^6+1) D0.                            (3.1)
```

Taking the r-th Frobenius power, for r=2^a, yields

```
beta W_(r,first)+alpha W_(r,second)
  = (x^(6r)+1) C^r+(y^(6r)+1) D0^r.                 (3.2)
```

For clarity, the period-Tor coordinates of a lifted physical cycle
with syndrome `(x^ell+1) C+(y^m+1) D0` are precisely the classes
of C and D0 in the plane module. This follows directly by chasing
the two augmentations of the balanced-Tor double complex. A different
physical lift changes these coefficients by plane boundaries or
period relations, and hence not on the surviving M0. Thus (3.2)
gives the coordinates `([C^r],[D0^r])` of W_r.

Let `omega^2+omega+1=0`. The point `(x,y)=(omega,omega^2)`
annihilates both reciprocal polynomials alpha,beta and is an
ordinary plane point. At this point,

```
C=omega^2,       D0=1,
(C^r,D0^r)=(omega^(2r),1).
```

Since 3 does not divide a power of two, the two displayed values
are nonzero and unequal. Therefore the two plane-module components
are nonzero and unequal. By the all-size parity theorem W_r is
mixed for **every** r=2^a, including r=1. This proves its
nontriviality as well. It does not need a finite member class gate,
a formal-series truncation, or an assumption about injectivity of
the first Frobenius map.

As an independent consistency check, S2's W4 gate supplies an odd
dual for each of the three index-two covers. Combined with §§1–2,
it gives a second proof: W4 mixed forces W2 and W1 mixed, and all
later doublings preserve mixedness on the reduced square image.

**Conclusion:** every W_(2^a), for a>=0, lies in the original
square's mixed class sector. The construction is not missing the
square discount merely because it started in a cylinder class.
Its physical witness weights are still `6*3^a`, not the conjectured
`12*2^a-6` once a>=2. The class-minimum problem and a genuinely
fresh-scale boundary correction remain open.
